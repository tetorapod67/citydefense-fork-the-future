# CityDefense: Fork the Future

**A Rewindable Multi-Agent Crisis City Builder**

> **The chat is temporary. The city remembers.**

CityDefense explores reversible delegation in a crisis-management city builder. Temporary browser-agent threads can operate persistent, role-scoped city seats through WebMCP, while the human City Owner retains replay and branching authority.

## Current bootstrap status

This public repository has been created as the canonical submission repository. The full sanitized application source and complete English documentation are being imported through the project bootstrap workflow.

A durable Gate 1 deployment already exists:

- **Live site:** https://citydefense-fork-the-future.suguri-a.chatgpt.site
- **Current proof status:** build, automated tests, deployment health, server-backed persistence, and top-level WebMCP registration are present; the final host-level Site Tools invocation proof remains pending.

## Frozen P0 scope

- Tutorial crisis: `CRISIS_SUBSTATION_ARC_FIRE`
- Golden-demo crisis: `CRISIS_AVALANCHE`
- Agent seat: `SENTINEL-01`
- Agent seat: `PLANNER-01` — Planner / Responder
- Replay and branch creation: human City Owner only

The wider forty-crisis, transport, science-fiction, fantasy, and hybrid catalogs are expansion design data rather than currently playable P0 runtime claims.
